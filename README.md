# Data Science Portfolio

A growing collection of applied data science projects, separate from the domain-specific work in my other repos (materials science simulation in [`BA_Natural_Sciences_Cambridge`](https://github.com/Thomas-J-Fish/BA_Natural_Sciences_Cambridge), quantitative finance in [`Quant_Portfolio`](https://github.com/Thomas-J-Fish/Quant_Portfolio)). The focus here is general-purpose data science technique, applied to a range of datasets and problems rather than one domain.

## Planned coverage

- **Exploratory data analysis & statistical inference** — cleaning, visualisation, hypothesis testing on real-world datasets.
- **Classical machine learning** — classification and regression pipelines, feature engineering, model evaluation (cross-validation, precision/recall/ROC, calibration).
- **Time series & simulation** — forecasting, resampling methods, Monte Carlo techniques.
- **Deep learning & computer vision** — CNN and image-to-image architectures, applied to structured scientific imagery.
- **LLM evaluation** — building evaluation pipelines and bias/fairness metrics for language model outputs.

Each project will get its own subfolder with a README covering the dataset, method, and results, in the same style as the rest of my repos.
